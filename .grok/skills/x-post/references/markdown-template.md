# Markdown 出力テンプレート

`outreach/x/YYYY-MM-DD.md` に保存する際は、以下の構造を厳守する。
`YYYY-MM-DD` は実行日（ユーザーの環境の今日の日付）を使う。

## Phase 1 のみ完了時（トレンド選出）

```markdown
# X 投稿ドラフト — YYYY-MM-DD（Phase 1）

## Phase 1: トレンド選出

### 採用トレンド
- キーワード:
- ハッシュタグ:
- 採用理由:

### 除外したトレンド（例）
- ...

### 次のアクション
1. https://tarot.scryer.workers.dev で 1 枚引き
2. 悩み欄に「（キーワード）」を入力
3. カード選択 → 「画像を保存」
4. `/x-post （画像パス） （カード名）・（正逆）` で Phase 2
```

## Phase 2 完了時（全文）

```markdown
# X 投稿ドラフト — YYYY-MM-DD

## メタ情報
- 投稿アカウント: https://x.com/TarotScryer
- 運営者: しいたけ. — https://x.com/shiitake7919
- スプレッド: single
- 選出トレンド: （キーワード + 採用理由）
- 悩み入力キーワード: （TarotScryer に入力した文言）
- カード: （例: 星・逆位置）
- 画像: /absolute/path/to/tarot-result.png

## トレンド調査メモ
- 調査日: YYYY-MM-DD
- 取得元: getdaytrends / WebSearch
- 採用トレンドと理由:
- 除外したトレンドと理由:

## ハッシュタグ
- Post A: #（トレンド） #タロット #占い
- Post B: #タロット #タロット占い #占い

## Post A: トレンド + 今日の1枚

### コピペ用（タグ込み・そのまま X に貼る）
```
（トレンドフック + 1枚引き）
【カード名・正逆】
（キーワードを活かしたヒント1文）

#（トレンド） #タロット #占い
```

**合計文字数:** N（150字以内）
**画像:** 添付する（tarot-result.png）
**リンク:** なし

## Post B: Post A 連動（招待）

### コピペ用（タグ込み・そのまま X に貼る）
```
{Post Aのヒント}、と{カード略称}が言ってた。
{トレンド}の余韻が残ってる人は、同じテーマで3枚引きも試せます。裏向きから直感で。
https://tarot.scryer.workers.dev

#タロット #タロット占い #占い
```

**合計文字数:** N（220字以内）
**連動カード:** Post A と同じカード名
**画像:** なし
**リンク:** https://tarot.scryer.workers.dev

## 手動投稿チェックリスト
- [ ] 自動投稿ツールは使わない（X 規約配慮）
- [ ] トレンドタグが投稿内容と意味的に関連しているか確認
- [ ] Post A の「コピペ用」ブロックをそのままコピー
- [ ] 画像を添付（Post A）
- [ ] X の文字数カウンターで切れていないか確認
- [ ] Post A を @TarotScryer から投稿
- [ ] （任意・別日）Post B の「コピペ用」をコピーして投稿
```

## 文字数の数え方

- **Post A**: コピペ用ブロック全体（本文 + 空行 + ハッシュタグ行）
  - **目標 ≤ 140字**、**上限 150字**
- **Post B**: コピペ用ブロック全体（本文 + URL + 空行 + ハッシュタグ行）
  - **上限 220字**
- 日本語・記号・`#`・URL はすべて1文字として数える
- 絵文字は X 上で2字扱いになる場合がある。余裕を見て短めにする

## コピペ用ブロックの書き方

- fenced code block（```）内に、**投稿そのもの**を書く
- ユーザーはこのブロックを1回コピーして X に貼るだけでよい
- 本文とハッシュタグを別欄に分けない
