# Markdown 出力テンプレート

`outreach/x/YYYY-MM-DD.md` に保存する際は、以下の構造を厳守する。
`YYYY-MM-DD` は実行日（ユーザーの環境の今日の日付）を使う。

```markdown
# X 投稿ドラフト — YYYY-MM-DD

## メタ情報
- アカウント: https://x.com/TarotScryer
- スプレッド: single | three
- カード: （例: 愚者・正位置 / 状況:○○・課題:○○・助言:○○）
- 画像: /absolute/path/to/tarot-result.png

## ハッシュタグ調査メモ
- 調査日: YYYY-MM-DD
- 調査クエリ: （使用した検索語を列挙）
- Post A 採用タグと理由:
  - #タグ名 — 理由
- Post B 採用タグと理由:
  - #タグ名 — 理由

## Post A: 今日の1枚

### コピペ用（タグ込み・そのまま X に貼る）
```
（挨拶 + 一枚引き）
【カード名・正逆】
（キーワードを活かしたヒント1文）

#タロット #占い #今日の運勢
```

**合計文字数:** N（本文 + 改行 + ハッシュタグ。150字以内であること）
**画像:** 添付する（tarot-result.png）
**リンク:** なし

## Post B: Post A 連動（招待）

### コピペ用（タグ込み・そのまま X に貼る）
```
今日の{カード名}、…
（体験訴求 + 1枚/3枚の選択肢）
https://tarot.scryer.workers.dev

#タロット #タロット占い #占い
```

**合計文字数:** N（本文 + URL + 改行 + ハッシュタグ。220字以内であること）
**連動カード:** Post A と同じ（1枚引き=そのカード、3枚引き=状況ポジション）
**画像:** なし
**リンク:** https://tarot.scryer.workers.dev

## 手動投稿チェックリスト
- [ ] 自動投稿ツールは使わない（X 規約配慮）
- [ ] Post A の「コピペ用」ブロックをそのままコピー
- [ ] 画像を添付（Post A）
- [ ] X の文字数カウンターで切れていないか確認
- [ ] Post A を投稿
- [ ] （任意・別日）Post B の「コピペ用」をそのままコピーして投稿
```

## 文字数の数え方

- **Post A**: コピペ用ブロック全体（本文 + 空行 + ハッシュタグ行）を数える
  - **目標 ≤ 140字**、**上限 150字**（実運用でタグ込み147字付近が限界となったため）
- **Post B**: コピペ用ブロック全体（本文 + URL + 空行 + ハッシュタグ行）を数える
  - **上限 220字**
- 日本語・記号・`#`・URL はすべて1文字として数える
- 絵文字（☀️🌙等）は X 上で2字扱いになる場合がある。余裕を見て短めにする

## Post A のハッシュタグ（デフォルト）

調査で問題がなければ、毎回この **3個固定** を使う（計約16字）:

```
#タロット #占い #今日の運勢
```

Web 調査で代替が明らかに優れている場合のみ、同数（3個）・同程度の長さに差し替える。

## Post B のハッシュタグ（デフォルト）

```
#タロット #タロット占い #占い
```

## コピペ用ブロックの書き方

- fenced code block（```）内に、**投稿そのもの**を書く
- ユーザーはこのブロックを1回コピーして X に貼るだけでよい
- 本文とハッシュタグを別欄に分けない
