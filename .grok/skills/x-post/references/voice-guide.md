# X 投稿トーンガイド

TarotScryer の X 投稿専用。アプリ本体（MOL・内省トーン）とは**意図的に分離**する。

## 基本方針

- #今日の運勢 #タロット #占い のタイムラインに**自然に溶け込む**
- 親しみやすい占い師が「今日のカード」を紹介している感じ
- 詳細な解釈は添付画像に任せ、本文はフック + ヒントに留める
- **コピペ用ブロック1つ**で X にそのまま貼れる長さに収める

## 使う表現

- 「今日の運勢」「今日の一枚」
- 「カードが伝えるメッセージ」
- 「ちょっとしたヒント」「今日のポイント」
- カード名（日本語）+ 正位置/逆位置
- キーワードを1〜2語自然に織り込む（例: 始まり・自由・可能性）

## 避ける表現

- MOL の問いかけ（「この状況の背後に、あなたが大切にしている価値観は…」）
- 心理療法用語（知覚制御、高次の目的、内省スプレッド 等）
- 決定論的な未来予言（「絶対うまくいく」「運命が決まった」「必ず恋が成就」）
- 過度なオカルト表現（「宇宙からの強いメッセージ」「魂の導きが…」）
- 医療・法律・投資アドバイス

## 挨拶と投稿時刻

投稿時刻に合った表現を使う。**矛盾する組み合わせは避ける**。

| 時間帯 | 挨拶の例 |
|--------|---------|
| 朝（〜11時） | `おはようございます☀️` |
| 昼以降〜夜 | `こんばんは🌙` または挨拶なしで `今日の運勢、` |
| 深夜（0時〜5時） | `おはよう` は使わない。`今日の運勢、` または `深夜の一枚、` |

## Post A（今日の1枚）

**目的**: タイムラインの「今日の運勢」投稿と同じノリで、カード結果を共有する。

**3行テンプレ**（タグ込み合計 ≤ 140字を目標）:

```
{挨拶 or フック} {一枚引き}
【{カード名}・{正逆}】
{キーワード1〜2語} + 今日のヒント（1文）

#タロット #占い #今日の運勢
```

**1枚引き（single）**: 主役カード1枚にフォーカス。

**3枚引き（three）**: 状況ポジションのカードを主役に。課題・助言は画像に任せる。

## Post B（Post A 連動・招待）

**目的**: Post A を見た人に「続き」を自然に促す。汎用チラシではなく、**今日引いたカードの延長**として書く。

**必須ルール**:
- 1文目に **Post A と同じカード名**（日本語）を入れる
- 3枚引きの場合は **状況ポジション**のカード名を使う
- 体験訴求（裏向きカード・直感で選ぶ）を含める
- `TarotScryer` サービス名は本文に入れない（URL のみ）

**1枚引き → Post B テンプレ**（タグ込み ≤ 220字）:

```
今日の{カード名}、もう少し深く見たい方へ。
裏向きのカードから直感で選ぶだけ、3枚引きも無料です。
https://tarot.scryer.workers.dev

#タロット #タロット占い #占い
```

**3枚引き → Post B テンプレ**:

```
今日の{状況カード名}、気になった方へ。
悩みを書いて3枚引き（状況・課題・助言）もできます。
裏向きのカードから直感で選ぶだけ。
https://tarot.scryer.workers.dev

#タロット #タロット占い #占い
```

**トーン**: 押し売りしない。Post A の読者へのさりげない招待。

**悪い例**:
```
タロットに興味がある方へ。TarotScryer で無料の一枚引き。
```
（→ Post A と無関係な汎用プロモ。カード名・体験がない）

## 長さ

| 投稿 | カウント対象 | 目標 | 上限 |
|------|-------------|------|------|
| Post A | コピペ用ブロック全体 | ≤ 140字 | 150字 |
| Post B | コピペ用ブロック全体 | ≤ 180字 | 220字 |

- 詳細は画像（Post A）に載るため、本文は短くてよい
- 絵文字は X で2字扱いになりうるため、余裕を持つ

## 免責

- 本文に免責文は**入れない**
- 画像内の「内省のきっかけ」免責に任せる

## 良い例（Post A・コピペ用）

```
こんばんは🌙 土曜の運勢、一枚引きました。
【教皇・正位置】
信頼できる人の助言や、慣れたやり方がヒントに。伝統を尊重しつつ、自分らしい答えを。

#タロット #占い #今日の運勢
```

## 悪い例（Post A）

```
おはようございます☀️ 土曜日深夜の運勢、一枚引きました。
```
（→ 挨拶と時刻が矛盾）

```
今日のカードが示すのは、あなたの高次の目的と現在の認知状態のズレです。
```
（→ MOL・内省トーン。X タイムラインに馴染まない）
