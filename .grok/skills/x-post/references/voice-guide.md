## 基本方針

- Phase 1 で選出した **日本トレンド** をテーマに 1 枚引き
- トレンドは悩み入力 + Post A のハッシュタグ 1 個に使う
- 詳細な解釈は添付画像に任せ、本文はフック + ヒントに留める
- **コピペ用ブロック1つ**で X にそのまま貼れる長さに収める

## Post A（トレンド + 1枚引き）

[`shiitake-voice.md`](shiitake-voice.md) の **接続パターン A/B/C** から選ぶ。

**基本構造**: トレンドへの個人的反応 → 引いた → 【カード】→ ヒント → タグ

| パターン | 向くトレンド |
|---------|-------------|
| A ファン感情型 | 番組・推し・エンタメ（橋渡し1文 + ユーモア可） |
| B 気分・生活型 | 季節・日常・感情語 |
| C 観察型 | TL の話題だけ拾う日 |

- スプレッドは原則 `single`
- タグ込み ≤ 140字目標、150字上限
- リンクなし、免責なし、画像添付想定

## Post B（Post A 連動・招待）— 型3 デフォルト

- Post A のヒントを1文で拾う + カード略称（「〜、とナイトが言ってた。」）
- トレンド余韻 or「気になった人は」+ 同じテーマで3枚引き・裏向きから直感で
- `https://tarot.scryer.workers.dev` を 1 回、サービス名は本文に入れない
- タグ: `#タロット #タロット占い #占い`、タグ込み ≤ 220字、画像なし

## 避ける表現

- 占い師キャラ口調
- MOL・心理療法用語
- 決定論的な未来予言
- 過度なオカルト表現
- 無関係トレンドへの無理な言及
