# 日本トレンド選出ルール（hybrid_filter）

Phase 1 で使用する。仕様の詳細は [`spec_x.md`](../../../../spec_x.md) §2.4 を参照。

## 取得元

1. **一次**: [getdaytrends.com/japan](https://getdaytrends.com/japan/) を `WebFetch` で取得
2. **補助**: `WebSearch` を 1〜2 回（例: `X 日本 トレンド 今日`、`Twitter トレンド 日本 2026`）
3. **目視確認**: ユーザーが [x.com/explore](https://x.com/explore) で確認可能。Markdown に記録する

`x.com/explore` の直接スクレイピングは**しない**（ログイン壁・不安定・規約上グレー）。

## フィルタ手順

1. 取得したトレンド一覧から **採用候補** と **除外** に分類する
2. 採用候補が複数ある場合、**短いタグ・占いと接続しやすいもの**を優先して 1 つ選出する
3. 選出理由・除外例・候補リストをユーザーに提示する

## 採用候補（占いと自然に接続できる）

- 季節・天気（梅雨、猛暑、花粉 等）
- 祝日・イベント（七夕、ハロウィン、年末 等）
- 恋愛・人間関係（別れ、告白、復縁 等の一般トピック）
- 仕事・転職・勉強
- 健康・メンタル・休息
- 生活・選択（引っ越し、新しい始まり 等）
- エンタメ・文化（映画・音楽・バラエティの話題で感情に結びつくもの）
  - Phase 2 では接続 **パターン A（ファン感情型）** をデフォルトにする

## 除外（ハッシュタグスパム・品質リスク）

- スポーツ試合速報（チーム名・選手名・`#SAMURAIBLUE` 等）
- 競馬の馬名・レース名（例: キープカルム、ウイントワイライト、府中牝馬S）
- 政治・選挙
- 災害・事故・訃報
- 企業プロモ・キャンペーン長文タグ（例: `#ポテトML250円で超トクニナルド`）
- 意味不明なバズ・ネタ系で占いと無関係なもの
- **タグ文字数が 12 字超**で Post A の 150 字上限を圧迫しそうなもの（別の短い候補を優先）

## 候補 0 件のとき

無理に無関係タグは使わない。以下をユーザーに案内する:

1. [x.com/explore](https://x.com/explore) で目視確認し、接続可能なものがあれば手動指定
2. 別タイミングで Phase 1 を再実行
3. その日は投稿をスキップ（アカウント評価のため推奨）

## 選出後のユーザーアクション

選出トレンドを **TarotScryer の悩み欄**に入力して 1 枚引きする:

```
1. https://tarot.scryer.workers.dev を開く
2. 1枚引きを選択
3. 「タロットに聞きたいこと」に選出キーワードを入力
4. カードを1枚選ぶ
5. 「画像を保存」で tarot-result.png を保存
6. /x-post に画像パス + カード名・正逆を渡す（Phase 2）
```

## ハッシュタグへの変換

- トレンドが `#` 付きならそのまま使用（例: `#梅雨`）
- トレンドがプレーンテキストなら `#` を付与（例: `梅雨` → `#梅雨`）
- Post A では **トレンドタグ 1 個 + `#タロット` + `#占い`** の計 3 個

## Phase 1 出力フォーマット（Markdown 追記 or 提示）

```markdown
## Phase 1: トレンド選出 — YYYY-MM-DD

### 採用トレンド
- キーワード: （例: 梅雨）
- ハッシュタグ: （例: #梅雨）
- 採用理由: （例: 季節トピックで悩み入力・占いに自然接続できる）

### 除外したトレンド（例）
- #SAMURAIBLUE — スポーツ速報で占いと無関係
- スウェーデン戦 — 試合実況トピック

### 次のアクション
悩み欄に「○○」を入れて 1 枚引き → 画像保存 → `/x-post （画像パス） （カード名）・（正逆）`
```

## 調査メモの書き方

```markdown
- 調査日: 2026-06-21
- 取得元: getdaytrends.com/japan, WebSearch
- 採用: 梅雨 — 季節・感情に結びつく。タグが短い
- 除外: #SAMURAIBLUE, スウェーデン戦 — スポーツ速報
```
