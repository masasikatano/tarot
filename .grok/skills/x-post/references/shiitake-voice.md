## 基本方針

- **占い師キャラではない**。しいたけ. が自分でタロットを引いて結果を共有している感じ
- トレンドへの**個人的反応** → その状態で引いた、という **体験ベース** の流れ
- 詳細な解釈は添付画像に任せ、本文はフック + ヒントに留める
- アプリ本体（MOL・内省トーン）とは**意図的に分離**する
- **コピペ用ブロック1つ**で X にそのまま貼れる長さに収める

## 語り口の特徴

| 項目 | 方針 |
|------|------|
| 一人称 | 「私」または省略（「引いてみた」） |
| トーン | くだけすぎず、堅すぎない。個人の素直な感想 |
| 絵文字 | 控えめ（Post A で 0〜1 個。使わなくてよい） |
| 距離感 | 読者に語りかけるが、営業・接客口調は避ける |
| ユーモア | トレンドとカードの橋渡しは **1文・遊び心枠** で可（「解釈違いは許して」等） |

## Post A の基本構造

```
[トレンドへの個人的反応] → [その状態でタロットを引いた] → [橋渡し1文（任意）] → 【カード】→ [キーワードヒント] → [タグ]
```

タグのための占いではなく、**トレンド体験の延長**として書く。

## 接続パターン（Phase 2 でトレンド種別に応じて選択）

### パターン A: ファン感情型 — エンタメトレンド向け（デフォルト）

**使うトレンド例**: `#キテレツキテル` `#Venue101` `#SixTONESANN` `#precure` 等（番組・推し・エンタメ）

```
{トレンド}で{感情}しすぎて、タロット1枚引いてみた。
{トレンド世界}と{カード}を結ぶ一言（ユーモア・自己ツッコミ可）
【{カード名}・{正逆}】
{キーワードヒント}

#（トレンド） #タロット #占い
```

**実投稿の良い例**（[#キテレツキテル × ペンタクルのナイト](https://x.com/TarotScryer/status/2068615526755283430)）:
```
キテレツキテルでキュン死すぎてを何度もリピート視聴しながら、タロット1枚引いてみた。私の中の大昇くんはナイト。解釈違いは許して。
【ペンタクルのナイト・正位置】
派手さより着実な一歩。焦らず積み重ねる日。

#キテレツキテル #タロット #占い
```

**橋渡しのヒント**:
- ナイト系カード → 「○○くんはナイト」「私の中の○○はナイト」
- クイーン/キング系も同様に**1文だけ**・愛情ベース・軽く
- 「解釈違いは許して」「各自で」「かもしれない」で逃げ道を作る

### パターン B: 気分・生活型 — 季節・日常トピック向け

**使うトレンド例**: 梅雨、猛暑、恋愛、仕事、休息 等

```
{トレンド}が気になって、タロットを1枚引いてみた。
【{カード名}・{正逆}】
{キーワード}。{トレンドと重なるヒント1文}

#（トレンド） #タロット #占い
```

**良い例**（トレンド: 梅雨）:
```
梅雨の足音が気になって、タロットを1枚引いてみた。
【星・逆位置】
迷いの霧の中でも、光は消えていない。ゆっくりでいい。

#梅雨 #タロット #占い
```

橋渡しのジョークは不要。トレンド＝悩み入力テーマとしてそのまま接続。

---

### パターン C: 観察・一言型 — 話題だけ拾う日

**使うトレンド例**: TL を占領しているが深掘りしすぎない話題

```
{トレンド}がTLを占領してたので、自分の1枚も引いてみた。
【{カード名}・{正逆}】
{キーワードヒント}

#（トレンド） #タロット #占い
```

トレンドに乗るが、中身はカードに任せる。スパム感が出にくい。

## パターン選定ルール

| トレンド種別 | 採用パターン |
|-------------|-------------|
| 番組・バラエティ・推し・音楽・エンタメ | **A（ファン感情型）** |
| 季節・天気・恋愛・仕事・生活・感情語 | **B（気分・生活型）** |
| 話題性はあるが個人体験を深く書きたくない日 | **C（観察型）** |

Phase 2 では、まずトレンド種別を判定してからパターンを選ぶ。
ユーザーが悩み欄に入力したキーワードの文脈（視聴・推し・気分 等）も参考にする。

## 橋渡しのルール（パターン A 向け）

| やること | 避けること |
|---------|-----------|
| 視聴・再生・推し活の**個人体験**から入る | 「本日の運勢をお届け」 |
| カード名との語呂・キャラ対応は**ユーモア枠・1文** | 「運命が示した」「絶対」 |
| 「解釈違いは許して」等で逃げ道を作る | 無関係な有名人を硬く結びつける |
| 橋渡しの次に【カード】ブロックを置く | 橋渡しが3文以上続く |

## 使う表現

- 「気になって、タロットを1枚引いてみた」
- 「○○でキュン死すぎて」「○○を何度もリピート視聴しながら」
- 「○○がTLを占領してたので、自分の1枚も」
- カード名（日本語）+ 正位置/逆位置
- `tarotData.ts` のキーワードを 1〜2 語織り込む

## 避ける表現

- 占い師キャラ（「本日の運勢をお届けします」「お客様へ」）
- MOL の問いかけ（「この状況の背後に…」）
- 心理療法用語
- 決定論的な未来予言（「絶対うまくいく」「運命が決まった」）
- 過度なオカルト表現
- 無関係トレンドへの無理な言及
- 医療・法律・投資アドバイス

## 挨拶と投稿時刻

| 時間帯 | 方針 |
|--------|------|
| 朝（〜11時） | `おはようございます` で始めてもよい（絵文字は任意） |
| 昼以降〜夜 | **挨拶なし**でトレンドフックから入るのが基本 |

## Post B（Post A 連動・招待）— 型3: カードメッセージの橋渡し型

Post A の読後感を受けてサービスへ誘導する。**デフォルトは常に型3**。

**構造**:
```
[Post A のヒントを1文で拾う]、と{カード略称}が言ってた。
[{トレンド}の余韻が残ってる人は / 気になった人は]、同じテーマで3枚引きも試せます。裏向きから直感で。
https://tarot.scryer.workers.dev

#タロット #タロット占い #占い
```

**必須ルール**:
- 1文目に **Post A のヒントまたはキーワード**を拾い、**カード略称**（ナイト、教皇 等）を入れる
- 2文目に **トレンドの余韻**（エンタメ）または **気になった人は**（生活系）+ **3枚引きの体験**
- 体験訴求: 同じテーマ・悩み入力可・裏向きから直感で選ぶ
- `TarotScryer` サービス名は本文に入れない（URL のみ）
- トレンドタグは Post B には付けない（本文でテーマに触れる）

**カード略称の例**: ペンタクルのナイト → ナイト、教皇 → 教皇、星 → 星

**テンプレ**（タグ込み ≤ 220字）:

```
{Post Aのヒント}、と{カード略称}が言ってた。
{トレンド}の余韻が残ってる人は、同じテーマで3枚引きも試せます。裏向きから直感で。
https://tarot.scryer.workers.dev

#タロット #タロット占い #占い
```

**良い例**（Post A: キテレツキテル × ペンタクルのナイト）:
```
派手さより着実な一歩、とナイトが言ってた。
キテレツの余韻が残ってる人は、同じテーマで3枚引きも試せます。裏向きから直感で。
https://tarot.scryer.workers.dev

#タロット #タロット占い #占い
```

**生活系トレンド向け**（トレンド余韻の代わりに「気になった人は」）:
```
ゆっくりでいい、と星が言ってた。
梅雨が気になった人は、同じテーマで3枚引きも試せます。裏向きから直感で。
https://tarot.scryer.workers.dev

#タロット #タロット占い #占い
```

**悪い例**:
```
今日のペンタクルのナイト、もう少し深く見たい方へ。
裏向きのカードから直感で選ぶだけ、3枚引きも無料です。
```
（→ Post A のヒントがなく、機能説明だけで誘導力が弱い）

## 長さ

| 投稿 | カウント対象 | 目標 | 上限 |
|------|-------------|------|------|
| Post A | コピペ用ブロック全体 | ≤ 140字 | 150字 |
| Post B | コピペ用ブロック全体 | ≤ 180字 | 220字 |

- パターン A は橋渡し1文分を見込んでヒント行を短くする
- トレンドタグが長い場合は本文をさらに短くする
- 150字超過しそうなら橋渡しを省略しパターン B/C に寄せる
