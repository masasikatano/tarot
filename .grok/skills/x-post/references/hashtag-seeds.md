# ハッシュタグシードリスト

毎回 Web 調査の**起点**として使う。
`WebSearch` で日本語圏の X / 占いコミュニティでの使用実態を確認してから採用する。

## デフォルト（調査で問題なければそのまま使う）

### Post A: 3個固定

```
#タロット #占い #今日の運勢
```

- 合計約16字。Post A の文字数予算を圧迫しない
- 実投稿で5個（34字）だとタグ込み合計が限界に達したため、3個に削減

### Post B: 3個固定

```
#タロット #タロット占い #占い
```

Post B は Post A 連動の招待投稿。`#無料占い` は前面に出さず、体験・カード名を主役にする。

## シードタグ（調査・差し替え候補）

### コア
- `#タロット`
- `#占い`
- `#タロット占い`

### 運勢系（Post A 差し替え候補）
- `#今日の運勢`
- `#運勢`
- `#開運`

### タロット特化（**Post A では原則使わない** — 長い）
- `#タロットカード`（8字+）
- `#今日のタロット`（8字+）
- `#タロットリーディング`

### プロモ向け（Post B 差し替え候補）
- `#無料占い`
- `#オンライン占い`
- `#タロット無料`

## Web 調査手順

1. 以下のようなクエリで `WebSearch` を **2〜3回** 実行する:
   - `X タロット ハッシュタグ 2026`
   - `Twitter 占い ハッシュタグ 人気`
   - `今日の運勢 タグ 使われ方`
2. デフォルト3個が当日も有効か確認する
3. 差し替える場合も **3個のまま**、合計タグ文字数が **20字以内** を目安にする

## 選定チェックリスト

- [ ] 日本語圏で実際に使われているタグか
- [ ] 投稿内容と意味的に合っているか
- [ ] **3個**に収まっているか
- [ ] タグ込み合計が Post A ≤ 150字 / Post B ≤ 220字 に収まるか
- [ ] スパム・禁止系でないか

## 避ける傾向

- Post A で長いタグを5個並べる（`#タロットカード` `#今日のタロット` 等）
- 関係のないバズタグ
- 同一意味のタグを複数並べる

## 調査メモの書き方

```markdown
- 調査日: 2026-06-20
- 調査クエリ: X タロット ハッシュタグ / 今日の運勢 タグ
- Post A: デフォルト3個を採用（#タロット #占い #今日の運勢）— 調査で定番タグとして確認
- Post B: デフォルト3個を採用（#タロット #タロット占い #占い）
```
