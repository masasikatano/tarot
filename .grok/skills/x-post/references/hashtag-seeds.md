# ハッシュタグ・トレンド選定

Phase 1 のトレンド選出は [`trend-filter.md`](trend-filter.md) を参照。
ここでは Post A / Post B のタグ構成とコアタグを定義する。

## Post A: 3個固定

```
#（Phase1で選出したトレンド1個） #タロット #占い
```

- `#今日の運勢` はトレンドタグに置き換え（文字数節約）
- トレンドが `#` 付きならそのまま、なければ `#` を付与
- コア2個（`#タロット` `#占い`）は原則固定
- トレンドタグが 12 字超の場合は別候補に差し替え（`trend-filter.md` 参照）

## Post B: 3個固定

```
#タロット #タロット占い #占い
```

- トレンドタグは Post B には入れない
- 体験・カード名を主役に。`#無料占い` は前面に出さない

## コアタグ（常に Post A に含める）

- `#タロット`
- `#占い`

## トレンド選定チェックリスト（hybrid_filter）

- [ ] 日本の当日トレンドとして実在するか
- [ ] 占い・内省・生活の選択に**自然につながる**か
- [ ] 悩み入力テーマとして使えるか
- [ ] タグとして付けてもスパムにならないか
- [ ] **3個**に収まっているか
- [ ] タグ込み合計が Post A ≤ 150字 / Post B ≤ 220字 か
- [ ] スパム・禁止系でないか

## 避ける傾向

- スポーツ・政治・悲報系トレンドへの無関係なタグ付け
- 長いプロモタグ + コアタグで文字数オーバー
- トレンドタグ + 占いタグを合計 6 個以上並べる
- 同一意味のタグを複数並べる

## 調査メモの書き方

```markdown
- 調査日: 2026-06-21
- 取得元: getdaytrends.com/japan, WebSearch
- 採用トレンド: #梅雨 — 季節トピックで悩み入力に自然接続
- Post A: #梅雨 #タロット #占い
- Post B: #タロット #タロット占い #占い
- 除外: #SAMURAIBLUE — スポーツ速報で占いと無関係
```
